# Style direction — hệ thiết kế, không chỉ bảng màu

Mục đích / người đọc / reference chính:
Tính cách mong muốn mô tả bằng quan hệ thị giác, không chỉ tính từ:

| Quyết định | Hướng được chọn | Lý do và giới hạn |
|---|---|---|
| Composition | | Phần chung, phần khác, focal point, đường đọc |
| Mật độ và nhịp | | Vùng gọn, vùng chi tiết, sự lặp có nghĩa |
| Component | | Silhouette của operator, dữ liệu và đối tượng phụ |
| Tỷ lệ | | Quan hệ chữ–khối và các cấp lớn/nhỏ |
| Typography | | Nhãn chính/phụ/toán; cỡ/weight tương đối; xuống dòng |
| Color | | Vai trò màu; nền/đối tượng/nhấn; không tự đổi thang dữ liệu |
| Line | | Viền nhóm/module/nội bộ; quan hệ nét và arrowheads |
| Corner và khoảng đệm | | Góc, joins, padding phù hợp từng đối tượng |
| Negative space | | Khoảng để tách nghĩa hoặc đi đường nối |
| Caption / series consistency | | Điều dùng chung cho các figure trong paper |
